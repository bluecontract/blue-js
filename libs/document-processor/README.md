# document-processor

This library was generated with [Nx](https://nx.dev).

## Blue JS 5 compatibility

Blue JS 5 uses the BEX runtime for contract execution. JavaScript workflow
execution and QuickJS runtime compatibility are not part of the document
processor runtime surface.

## Building

Run `nx build document-processor` to build the library.

## Running unit tests

Run `nx test document-processor` to execute the unit tests via [Vitest](https://vitest.dev/).
